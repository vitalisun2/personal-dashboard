# Personal Dashboard MVP

Локальный адаптивный дашборд задач на .NET 8 + HTML/CSS/JS.

## Что уже есть

- `Backlog` и `Сегодня`.
- Быстрое добавление задачи из свободного текста.
- Короткий title + полное описание + раздел задачи.
- Разделы задач в `Backlog` и `Сегодня`.
- Клик по заголовку раздела сворачивает/разворачивает его.
- Глобальные кнопки «Свернуть всё» / «Развернуть всё» рядом с переключателем `Backlog / Сегодня`.
- Вложенные задачи визуально сдвинуты вправо.
- Очень лёгкий сине-серый оттенок строк разделов.
- Отдельная страница задачи с названием раздела.
- Перенос `Backlog → Сегодня` и `Сегодня → Backlog`.
- В списке перенос обозначен только стрелками `→ / ←`.
- На странице задачи: `→ Сегодня / ← Backlog`.
- Статусы только в `Сегодня`: `Новая → В работе → Завершена → Стикер (удаление)`.
- Цветовые точки: новая — нейтральная, в работе — синяя, завершена — зелёная.
- Фильтры: Все / Новые / В работе / Завершены.
- Адаптивная верстка: sidebar на desktop, bottom navigation на mobile.
- Все изменения сохраняются в `tasks.json` в корне приложения.

## Запуск

Нужен .NET 8 SDK.

```bash
dotnet run
```

После запуска открой адрес, который выведет `dotnet run` (обычно `http://localhost:5xxx`).

## Запуск в Docker (доступ через Tailscale из любого места)

```bash
cp .env.example .env      # при необходимости: URL Ollama, ключ OpenRouter
docker compose up -d --build
```

- Приложение слушает `:8080`, задачи хранятся в `./data/tasks.json` (bind-mount, переживают пересоздание контейнера).
- Контейнер видит Ollama хоста через `host.docker.internal:11434` (добавлен `host-gateway`).
- Для доступа из любой точки: `tailscale serve --bg 8080` (или просто открыть порт в тайлнете) — приложение доступно только устройствам твоей Tailscale-сети, не публичному интернету.

## Структура

- `Program.cs` — API, JSON-хранилище и LLM-агент с каскадом провайдеров.
- `tasks.json` — данные задач, включая поле `section`.
- `wwwroot/index.html` — интерфейс.
- `wwwroot/styles.css` — адаптивные стили.
- `wwwroot/app.js` — UI-логика и работа с API.
- `tests/` — интеграционные тесты (xunit).

## Агент для title/description/section

Сырой надиктованный текст разбирается каскадом провайдеров (`LlmTaskAgent`), интерфейс `ITaskAgent` получает список существующих разделов:

1. **Подписочный DeepSeek через OpenRouter** — основной разборщик, включается автоматически, если задан `OPENROUTER_API_KEY` (модель — `OPENROUTER_MODEL`, по умолчанию `deepseek/deepseek-v4-flash-0731`).
2. **Локальная Ollama** — fallback, `qwen3:4b-instruct-2507-q4_K_M` (по умолчанию `http://localhost:11434`, переопределяется через `OLLAMA_URL` / `OLLAMA_MODEL`). Запрос идёт со строгим JSON-грамматикой (`response_format: json_schema`), модель физически не может выдать кривой JSON.
3. **Эвристика без сети** — title из первого предложения, раздел — по ключевым словам и явному упоминанию существующего раздела. Срабатывает, когда оба LLM лежат.

Приложение всегда отвечает, даже если все LLM лежат.

Модель получает в системном промпте список существующих разделов и должна выбрать самый подходящий (или предложить новое короткое название).

Настройки окружения:
- `TASKS_FILE` — путь к JSON с задачами (по умолчанию `tasks.json` в корне приложения; в Docker — `/data/tasks.json`).

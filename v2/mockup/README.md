# Personal Dashboard v2 — UI/UX макет

Автономный макет новой версии Personal OS: база знаний, планирование, задачи и чат. Данные пока хранятся в памяти страницы и сбрасываются при её обновлении. Это исходник интерфейса для дальнейшей реализации `v2`, без подключения к API старого приложения.

## Просмотр

Из этой папки запустите локальный сервер:

```powershell
python -m http.server 8766
```

Откройте `http://127.0.0.1:8766/index.html`. Можно также открыть `index.html` напрямую в браузере.

Файлы `index.html`, `*.css` и `*.js` работают вместе; при переносе интерфейса в приложение сохраняйте относительные пути или обновите ссылки в HTML.

Краткое описание сценариев интерфейса: [UX.md](UX.md).
